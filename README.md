💰 EdVyro Expense Tracker

📌 Project Description

The Expense Tracker is a beginner-friendly C++ command-line application that helps users record and manage their daily expenses.

It provides a simple menu-driven interface to add expenses, view expense records, calculate category-wise totals, and calculate the overall spending amount.

🚀 Features

- Add new expenses with a description, category, and amount.
- List all recorded expenses.
- Calculate total expenses by category.
- Calculate overall expenses.
- Validate expense amounts and reject invalid or non-positive values.
- Display clear and readable terminal output.
- Simple menu-driven interface.

🛠️ Technologies Used

- Programming Language: C++
- Compiler: GCC (g++)
- IDE: Visual Studio Code

▶️ How to Run

1. Compile the program

g++ main.cpp -o expense_tracker

2. Run the program

Windows:

.\expense_tracker.exe

📋 Menu Options

1. Add Expense
2. List Expenses
3. Category Total
4. Overall Total
5. Exit
